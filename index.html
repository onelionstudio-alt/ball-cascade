  2. LaunchThe practice flow is unscored. Launch starts your finite ball budget.
  3. Make it cascadeFeed the lit pockets. Burst launches use the same budget. Red teeth destroy balls.

Destroyed counts every ball broken during a challenge, including split copies. Practice is unscored. A split ball counts once per target pocket for each original. Accuracy and original-loss limits measure original balls, not copies; a lost branch is not a lost original if another branch lands safely.

First clears and new stars earn coins. Failed attempts are free. Reloading restarts unfinished physics; completed levels, layouts and upgrades stay saved.
